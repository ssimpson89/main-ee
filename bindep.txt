# System packages, shared by every execution-environment variant.
#
# Profile tags:
#   [platform:rpm]          installed into the final image
#   [platform:rpm compile]  builder stage only, kept out of the final image
#
# Do not add python-versioned packages here (python3-devel,
# python3.11-devel, ...). bindep cannot template the interpreter name, and
# the two variants use different ones. They are installed per variant via
# $PYPKG in additional_build_steps instead.
#
# Do not pin an architecture (libxcrypt-compat.x86_64). dnf resolves the
# right arch on its own, and a hardcoded one breaks the arm64 build.
